## [1.0.0] - 2026-11-04

### Adicionado

- `token.yaml`: Token API (emissão de tokens JWT e JWKS).
- `dss.yaml`: DSS (Discovery and Synchronization Service).
- `sw-uss.yaml`: endpoints que todo SW-USS expõe aos demais participantes.
- `sw-uss-homologacao.yaml`: interfaces de teste da homologação (Flight Planning, Remote ID Injection, Versioning).
- `gerenciador-constraints.yaml`: SW-USS Gerenciador de Constraints.
- `provedor-zona-utm.yaml`: Provedor de Zona UTM.
- `provedor-altitude-terreno.yaml`: Provedor de Altitude de Terreno.
